本版集中优化悬浮窗动画、底部定位、连续拍题流畅度、对话输入与公式显示。

- 展开和收回统一时长与动画进度；靠近屏幕底部、边缘或键盘时采用当前落点，避免旧坐标回弹，并处理收回途中立即重开的情况。
- 连续拍题时彗星保留进度，减少重复布局；截图编码、大请求构建和公式解析移到后台。
- 左球「答案」直接展开对话输入框。输入框默认紧凑单行，多行时再增长。
- 新增离线 MathJax 扩展与公式缓存，补充化学式、物理记号、对齐方程、矩阵、分段函数等；支持 math/latex/tex 公式块，并修复公式旁的文字和代码块处理。

公式渲染不需要联网；复杂公式需要手机系统 WebView 可用。不支持完整 TeX 文档、TikZ/PGFPlots 或任意宏包，无法渲染时保留源码。
