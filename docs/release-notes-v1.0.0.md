做题小助手 **1.0.0**，基于 [HanakoAI](https://github.com/zyf2007/HanakoAI) 改良并独立维护，遵循 AGPL-3.0。

## Changelog

- 一体式双球悬浮窗：右球整屏截图，左球可选区域，答案逐字显示；支持复制、重试与追问。
- 首页与设置共用固定顶部栏和黑白界面；应用内、桌面和自适应图标统一为 SVG 绘制的低多边形猫。
- 优化首页 / 设置的点击、滑动切换；预保留相邻页面，减少首次启动时的布局变化；设置及历史解析、Shizuku 状态检查移至后台线程。
- 保留系统录屏与 Shizuku 两种截图方案；主页可切换并查看说明。
- 独立配置多模态、文本、OCR 模型，支持留空；按照模型和接口映射思考强度。
- 支持调整悬浮窗尺寸、透明度、答案字号；历史记录集中到设置。
- 移除 Kirari Network 专属服务依赖，保留已有有效模型配置和历史数据。

## 下载说明

要求 Android 7.0 或更新系统。**新用户通常选择 `ZuotiAssistant-1.0.0-full-arm64-v8a.apk`。**

| 安装包 | 用途 |
| --- | --- |
| `full-arm64-v8a` | 推荐，内置本地中文 OCR，适合大多数现代手机 |
| `full-armeabi-v7a` | 内置本地 OCR，适合支持 32 位应用的设备 |
| `lite-arm64-v8a` | 较小，不含本地 OCR，使用多模态或云端 OCR |
| `lite-armeabi-v7a` | Lite 的 32 位版本 |
| `full-dev-upgrade-arm64-v8a` | 仅供已有「做题小助手 测试版」覆盖升级 |

普通包使用独立正式签名，包名为 `fun.kirari.hanako`。旧测试版升级包保留 `fun.kirari.hanako.dev` 和原测试证书、应用名，启用与正式包相同的 R8 优化且不可调试。二者的数据各自独立，请按当前安装版本选择。**保留配置和历史记录时，请勿先卸载旧应用。**

首次使用需配置自己的模型服务和 API Key，并授予悬浮窗、截图相关权限。Shizuku 需单独安装、启动和授权；手机重启后通常需再次启动服务。截图只会发送到自行配置的服务。不同签名的上游 Hanako 安装不能直接由普通包覆盖。
