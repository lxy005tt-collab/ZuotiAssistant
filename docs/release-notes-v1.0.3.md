做题小助手 **1.0.3**，让连续截图接着同一段对话。基于 [HanakoAI](https://github.com/zyf2007/HanakoAI) 改良，遵循 AGPL-3.0。

## Changelog

- 每次启动悬浮窗从新对话开始；右球截图、区域截图和文字追问延续本次上下文。收起气泡不清空，退出悬浮窗再启动才重新开始。
- 左球菜单新增「新题」，可在不退出悬浮窗的情况下重新开始；旧对话留在历史记录。
- 多模态保留每轮原图，OCR 保留各轮识别文字；回答和补图按消息顺序发送，同一对话的截图统一展示在历史详情中。
- 重试复用当前轮截图与识别结果，不重复添加附件；截图或识别失败不清空前文，图片丢失时明确提示。
- 后续截图仍支持联网搜索，搜索及回退请求保留完整上下文。
- 截图等待时只有动画，新回答开始后展开气泡并跟随最新内容滚动；保留紧凑的复制、重试、追问按钮栏。

## 使用说明

同一道题分屏显示时，直接连续点击右球即可。处理独立题目且不想带上前文时，点左球「新题」，然后截图。

会话沿用首次截图的多模态 / OCR 处理方式；切换方式后可点「新题」开始新对话。回到应用主页不会清空仍在运行的悬浮窗会话。历史记录可以继续追问，但新启动的悬浮窗不会自动恢复上一段历史对话。

完整上下文会增加请求用量；本版不自动压缩或省略题图，仍受模型上下文长度限制。

## 下载说明

新用户通常选择 `ZuotiAssistant-1.0.3-full-arm64-v8a.apk`，应用要求 Android 7.0 及以上。Full 内置本地中文 OCR，Lite 仅使用多模态或云端 OCR；`armeabi-v7a` 为 32 位版本。

已有旧测试版或 `dev-upgrade` 包的用户，请继续选择 `ZuotiAssistant-1.0.3-full-dev-upgrade-arm64-v8a.apk` 覆盖安装，**不要先卸载**。包名和升级证书延续，配置与历史记录保留。普通包与兼容包的数据独立。
